# Power BI Dashboard Blueprint

`F1_Race_Intelligence_PowerBI_Dataset.xlsx` is generated by `build_powerbi_master_package.py` **only from the module output files**, so every number in Power BI matches the Streamlit dashboards and the report. Regenerate it after `run_all_modules.py`:

```bash
.venv/bin/python build_powerbi_master_package.py
```

## What is in the workbook

| Sheet | Rows | Contents |
|---|---:|---|
| `Executive_KPI_Summary` | 10 | Headline numbers (dataset, classifier, pattern mining, clustering) |
| `Fact_Holdout_Predictions` | 1,359 | The champion XGBoost's real predictions for every 2022–2024 holdout entry: `raw_prob`, `norm_prob` (sums to 1 per race), `predicted_rank_in_race`, `is_winner_hit`, `winner_in_top3`, `confidence_tier` |
| `Dim_Drivers`, `Dim_Constructors`, `Dim_Circuits`, `Dim_Races` | 174 / 48 / 43 / 577 | 1994–2024 history: starts, wins, podiums, average grid and finish |
| `ML_Model_Comparison` | 7 | The 7 classifiers on the 2022–2024 holdout |
| `ML_Temporal_Validation` | 6 | Expanding-window ROC-AUC per season, XGBoost vs. baseline |
| `ML_Partition_Metrics` | 4 | Train / validation / test / holdout metrics |
| `ML_ROC_Curve` | 101 | Champion ROC curve points |
| `ML_Feature_Importance` | 16 | XGBoost gain per feature |
| `ML_Association_Rules`, `ML_Frequent_Itemsets`, `ML_Support_Sweep` | 1,393 / 414 / 4 | FP-Growth / Apriori output and the support sweep |
| `CL_Driver_Season_Clusters` | 703 | Every driver-season with its K-Means tier and PCA coordinates |
| `CL_Cluster_Profiles` | 3 | Tier centroids |
| `CL_Algorithm_Comparison` | 6 | The 6 clustering algorithms and their scores |
| `DAX_Measures_Reference` | 7 | Ready-to-paste DAX measures |

## Opening it

Power BI Desktop runs on Windows only. On a Mac, use **Power BI in the browser** (app.powerbi.com, with a work or school Microsoft account): *Create → Get data → Excel workbook* and pick the sheets you need.

1. Load the sheets.
2. Relationships: `Fact_Holdout_Predictions[race_id]` → `Dim_Races[race_id]`, `Fact_Holdout_Predictions[driver_name]` → `Dim_Drivers[driver_name]`, `Fact_Holdout_Predictions[constructor_name]` → `Dim_Constructors[constructor_name]`, `Dim_Races[circuit_name]` → `Dim_Circuits[circuit_name]` (all many-to-one).
3. Apply `F1_PowerBI_Theme.json` (*View → Themes → Browse*): the same purple / green / gray colours as the dashboards.
4. Add the measures from `DAX_Measures_Reference`.

## Suggested pages

| Page | Visuals |
|---|---|
| **Race predictor** (Dashboard 2) | Cards: `Winner Hit Rate %`, `Winner In Top 3 %`, `Avg Win Probability`. Slicer on `Dim_Races[race_name]` and `season`. Bar chart of `norm_prob` by `driver_name` for the selected race, coloured by `target_is_win`. |
| **Model comparison** (Dashboard 2) | Clustered bar of `roc_auc` / `pr_auc` by `algorithm` (`ML_Model_Comparison`); line chart of `roc_auc` vs `baseline_roc_auc` by `test_season`; line chart of `ML_ROC_Curve`; bar of `ML_Feature_Importance`. |
| **Pattern mining** (Dashboard 2) | Table of `ML_Association_Rules` filtered to `consequents` containing `Outcome_Winner`, sorted by `lift`; line chart of `apriori_candidates` vs `fp_tree_nodes` by `min_support` (`ML_Support_Sweep`). |
| **Driver tiers** (Dashboard 3) | Scatter of `pca_1` vs `pca_2` coloured by `cluster_name`; stacked column of driver-seasons per `season` by `cluster_name`; table of `CL_Cluster_Profiles`; bar of `silhouette` by `algorithm` (`CL_Algorithm_Comparison`). |
